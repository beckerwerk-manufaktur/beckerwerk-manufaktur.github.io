# Beckerwerk Manufaktur – Website

Statische Seite für GitHub Pages: Startseite, Impressum, Datenschutz. Keine Skripte, keine Cookies, keine externen Schriften.


## Veröffentlichen (einmalig)

1. Bei GitHub anmelden, oben rechts **+ → New organization → Free**, Name `beckerwerk-manufaktur`.
2. In der Organisation **New repository**, Name genau `beckerwerk-manufaktur.github.io`, **Public**.
3. Im Repository **Add file → Upload files**: `index.html`, `impressum.html`, `datenschutz.html`, `style.css` und den Ordner `assets` hochladen, dann **Commit changes**.
4. **Settings → Pages**: Source „Deploy from a branch“, Branch `main`, Ordner `/ (root)`, Save.
5. Nach wenigen Minuten ist die Seite unter `https://beckerwerk-manufaktur.github.io` erreichbar.

Eigene Domain später: unter Settings → Pages → Custom domain eintragen und beim Domain-Anbieter einen CNAME-Eintrag auf `beckerwerk-manufaktur.github.io` setzen.
